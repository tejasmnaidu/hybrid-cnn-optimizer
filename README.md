# Hybrid Optimization and CNN-Based Control for Harmonic Reduction in Multilevel Inverters Applied to Microgrids

This repository currently implements the local Streamlit interface foundation for the final BE AI/ML major project. The scientific model implementation, simulation, CNN training, HPFO optimization, and MATLAB integration will be added incrementally.

## Current stage

- Project stage: Interface/Foundation Development
- Interface readiness: foundation ready for local usage
- Algorithm implementation: pending

## Project structure

- `app.py` - Streamlit dashboard entry point
- `main.py` - application launcher
- `preprocessing/` - data loading and preprocessing placeholder
- `cnn/` - CNN placeholders for future work
- `optimization/` - optimization placeholders for future work
- `multilevel/` - legacy multilevel waveform scaffold
- `signal_processing/` - FFT/THD placeholders and utilities
- `data/raw/` - raw datasets should be placed here
- `data/processed/` - processed data outputs will go here
- `models/` - saved model artifacts will go here
- `results/` - generated figures and report data will go here

## Installation

```bash
python -m pip install -r requirements.txt
```

## Run locally

```bash
streamlit run app.py
```

## Notes

- The interface is designed to run without datasets, trained models, or MATLAB dependencies.
- Existing 8-level code is preserved as legacy scaffold code and is not presented as the final 31-level model.
- This version does not perform CNN training, optimization, model execution, or MATLAB integration.
